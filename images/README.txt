HOUSE RULES FOR PHOTOS
  • Only publish a photo of a child if you are their parent or guardian, or have that
    parent's or guardian's permission.
  • Never add a child's name, class or anything else that identifies them — not in the
    file name, caption or alt text.
  • If a parent asks for a photo to be removed, delete the file.
