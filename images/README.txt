St. Mary's Parents' Association — images folder
===============================================

Drop your own photographs in this folder using the exact file names below.
Nothing needs to be edited in the code: the website checks for each file and
uses it if it is there. If a file is missing, the illustrated version (or a
friendly placeholder) shows instead.

HERO PHOTOS (one per page)
--------------------------
images/scene-1.jpg   →  Home, The school
images/scene-2.jpg   →  What we do, What's on
images/scene-3.jpg   →  Privacy notice
images/scene-4.jpg   →  Get involved, Gallery
images/scene-5.jpg   →  News, Contact

  • Landscape, roughly 1600 × 900 pixels (any wide photo works).
  • Keep the subject in the middle-right; a soft panel sits over the left side.
  • Save as .jpg. No spaces in the file name.

GALLERY PHOTOS
--------------
images/gallery-1.jpg  through  images/gallery-9.jpg

  • Landscape, roughly 800 × 600 pixels.
  • Save as .jpg, numbered in the order you want them to appear.

HOUSE RULES FOR PHOTOS
----------------------
  • Only publish a photo of a child if you are their parent or guardian,
    or you have that parent's or guardian's permission.
  • Never add a child's name, class or anything else that identifies them —
    not in the file name, not in the caption, not in the alt text.
  • If a parent asks for a photo to be removed, remove the file and its
    gallery entry, and replace the caption.

To add a photo to the gallery, copy one <figure class="gallery-item"> block in
gallery.html and change the three numbers/texts: the image file name, the
caption, and the description used by screen readers.
