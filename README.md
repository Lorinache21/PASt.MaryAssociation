# St. Mary's Parents' Association, Enfield

Static website (plain HTML, CSS and a little JavaScript — no build step, no cookies, no third-party requests).

- Pages: `index`, `about` (school & Enfield), `what-we-do`, `events`, `news`, `get-involved`, `governance` (constitution & finances), `gallery`, `contact`, `privacy`.
- Colours come from the school crest: royal blue `#0a3590`, gold `#ffcf02`, green `#0b8a1c` (see `:root` in `style.css`).
- `documents/` holds the PA Constitution and FSSU Financial Guideline P10 PDFs.
- `images/README.txt` explains how to add school and Enfield photos.
- Contact: Stmaryspaenfield@gmail.com · Facebook: Stmaryspa Enfield
